# Vellazo Aromatique

Site estático (HTML + CSS + JS) da Vellazo Aromatique. Não precisa de build.

## Estrutura
- `index.html` — página única
- `css/style.css` — estilos
- `js/main.js` — comportamento do FAQ
- `assets/` — logo, fotos dos sabonetes e favicon

Para testar localmente, abra `index.html` no navegador.
